Linked List 
It is a linear data structure where elements are not stored in contiguous memory location but are instead together using pointers. Each Element in a linked list is called a node, which consist of data field and a reference to the next node in sequence.

Linked has two things at a Node:-
Data(Value) and Pointer (it will point to next node ke taraf)

and last node it has null pointer in a Linked List


Node Structure- A node in a single linked list typically has two field:
Data field- stores actual value(eg integer)
Pointer field(next) stores the address of next node
